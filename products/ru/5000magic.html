Основные характеристики и функции

  • Состоит из 3 программ управления раствором
  • Возможно управление по накопленной радиации для каждой программы
  • Базово: экран 7" — сенсорный ЖК
  • Раствор = A/B, кислота/щёлочь и доп. удобрения = 4 (базовая)
  • Раствор = A/B/C/D, кислота/щёлочь и доп. удобрения = 6 (опция)
  • EC-1 (управление) + pH-1 (управление) = базовая
  • Опция = EC-2 (дренаж) + pH-2 (дренаж)
  • 12 зон полива в каждой программе; объём = расход (расходомер — опция) / время (мин:сек)
  • Доп. удобрения по программам — прямая подача с включением/остановкой = базовая
  • Датчики EC Agrow-3000/5000 и Agrow-6000/7000 взаимозаменяемы = датчик pH общий
  • Поливной насос = нерж. сталь 3 л.с. + непрерывное смешивание = базовая
  • Защита = 3 фазы, 380 В — обрыв фазы / низкий уровень / насосы / сигнализация / Сигнализация EC / pH / расхода
  • Остальные функции аналогичны Agrow-5000
