Agrow-7000

Model No. HPA-7000

20yr export know-how. 5 programs. 6 nutrient types (A–F) proportional control.

Key Specifications & Features

  • 5 independent programs (radiation — 3 / moisture & ext. sensors — 2)
  • One radiation sensor drives 3 independent programs by accumulated radiation
  • In the 3 radiation programs, radiation [-Ec:00%] and moisture [+00%] coefficients apply
  • Nutrient — 6 (A~F) + acid/base + auxiliary fertilizer = 8 / irrigation zones = 16
  • Nutrient supply mode per program: proportional-integral / combined proportional
  • In combined mode, per-component (A~F) offset supply is possible (10%~90%)
  • Select nutrients per 5 programs: 6 (A~F) / acid-base / auxiliary fertilizer
  • Irrigation volume per 5 programs = time (min:sec) / flow (0000 L)
  • Option: flow meter = auto switch to other control if the meter fails in flow-based supply
  • Moisture & external sensor programs = program assignment per sensor (P-4/P-5)
  • 5 programs run independently by external sensors, time interval and set time
  • After irrigation in each of the 5 programs, valves can be flushed with raw water
  • For multi-crop growing: mixing tank drain and nutrient preparation on program change
  • Per-valve delay time can be entered when irrigation zones change (00 sec)
  • Standard EC sensors (2): EC-1 = control / EC-2 = monitor
  • Standard pH sensors (2): pH-1 = control / pH-2 = monitor
  • Option: EC-3 / pH-3 = reprocessing sensors; reprocessing range can be set, alarm and shut-off when reprocessed mixture outside the range enters
  • In-program EC/pH: alarm limits adjustable; safety device activates at limits
  • Sensor value calibration for EC-1/2/3, pH-1/2/3 and radiation sensor
  • Data: daily per 5 programs — irrigation count / per 16 valves — flow and irrigation time
  • 16 valves — average EC/pH stored 1 year and viewable. Radiation sensor
