Agrow-6000

Model No. HPA-6000

2022 #2 sales. 4 programs. Precise EC·pH. 16-zone irrigation.

View Catalog Catalog PDF Inquire Telegram
Manufacturer Hangaram Agricultural DevelopmentBrand Agrow🇰🇷 Made in Korea

Key Specifications & Features

  • 4 independent programs (radiation — 3 / moisture & ext. sensor — 1)
  • One radiation sensor drives 3 independent programs by accumulated radiation
  • In the 3 radiation programs, radiation [-Ec:00%] and moisture [+00%] coefficients apply
  • Nutrient = 4 (A~D) + acid/base + auxiliary fertilizer = 6 / irrigation zones = 16
  • Per 4 programs: select from 4 nutrients (A~D) / acid-base / auxiliary fertilizer
  • Per 4 programs: irrigation volume = time (min:sec) / flow (0000 L)
  • Option: flow meter = auto switch to other control if the meter fails in flow-based supply
  • Moisture & external sensor program = program assignment per sensor (P-4)
  • 4 programs run independently by ext. sensors, interval and set time (20 times)
  • After irrigation in each of the 4 programs, valves can be flushed with raw water
  • Standard: 1 EC sensor / 1 pH sensor
  • Option: EC-2 / pH-2 = reprocessing sensors; reprocessing range can be set, alarm and shut-off when reprocessed mixture outside the range enters
  • In-program EC/pH: alarm limits adjustable; safety device activates at limits
  • Sensor value calibration for EC-1/2, pH-1/2 and radiation sensor
  • Data: daily per 4 programs — irrigation count / per 16 valves — flow and irrigation time
  • Average EC/pH values of 16 valves stored for 1 year and viewable
